# AI and LLM Security Agent Systems Interview Prep

This project is a complete MkDocs Material learning site to prepare for Staff and Principal-level roles focused on AI and LLM security agent systems.

It maps role expectations to a practical study path across model behavior, security-aware agent architecture, tool orchestration, evaluation workflows, and production reliability.

## Run locally

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Start the docs server:
   ```bash
   mkdocs serve
   ```
3. Open the local URL shown in the terminal.
